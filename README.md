# 📚 StudyTogether Backend API

Backend server for the **StudyTogether Web Application**, built using **Node.js, Express, and MongoDB**.  
This API powers authentication, paper uploads, search, downloads, and admin management.

---

# 🚀 Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB (Mongoose)**
- **JWT Authentication**
- **Multer (File Upload)**
- **Helmet (Security)**
- **Express Rate Limit**
- **Morgan (Logging)**

---

# 📌 Features

### 🔐 Authentication

- User Registration
- User Login
- JWT Token Authentication

### 👤 User System

- View Profile
- Update Profile
- Delete Account

### 📄 Study Papers

- Upload PDF (Admin)
- View Papers
- Search Papers
- Filter by Subject
- Filter by Semester
- Pagination
- Preview PDF
- Download Papers

### ⭐ Engagement

- Paper View Counter
- Download Counter
- Rating System
- Trending Papers

### 🛡 Admin Panel

- Upload Papers
- Update Papers
- Delete Papers
- Manage Users
- Admin Statistics Dashboard
